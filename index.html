How it works

No plugin system, no lock-in. Each skill is a plain Markdown contract your agent loads on demand.

01

Drop it in

Copy or submodule the skills/ folder into your agent's environment. Every leaf has stable frontmatter and a SKILL.md.

02

Route by task

The agent discovers skills/**/SKILL.md, picks the platform skill when the problem is toolchain-bound, otherwise the matching universal workflow.

03

Follow the chain

Skills link to each other: version → preflight → artifacts → store submission. Compilation, review, and publication stay distinct, verifiable outcomes.

Get started

Clone it, or vendor skills/ into the project where your agent works. There is nothing to build — the catalog is the product.

# clone the catalog
git clone https://github.com/kimmandoo/app-skills.git

# or vendor the skills into your project
cp -R app-skills/skills /path/to/your/project/
